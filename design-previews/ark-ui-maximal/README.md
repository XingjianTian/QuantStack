# Quant Center Ark UI maximal previews

These two standalone prototypes compare two independent Ark UI family choices
at the same `maximal` application depth. They do not replace the production
Quant Center application.

- `endfield.html`: field-engineering control system; action-first, pale rail,
  charcoal control dock, signal-yellow selection, and route instrumentation.
- `corporate.html`: restrained studio identity; monochrome project narrative,
  acid-lime active rule, editorial sequencing, and quiet media choreography.

Both previews use only original CSS/SVG geometry and system font fallbacks. No
official logos, artwork, production bundles, or proprietary fonts are bundled.
The displayed tasks come from the current Quant Center information architecture;
no market price, latency, return, or other fabricated telemetry is shown.

Serve locally from this directory, then open either page:

```bash
python3 -m http.server 4174
```
